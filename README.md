# Midway Rapid Dine

A smart highway food pre-order platform that allows travelers to pre-book meals before reaching their destination.

## Overview

Midway Rapid Dine helps users:

* Select their travel route
* Choose food items
* Select nearby hotels/restaurants
* Pre-order meals
* Make payments before arrival

The platform is designed to reduce waiting time during travel and improve dining convenience on highways and midways.
